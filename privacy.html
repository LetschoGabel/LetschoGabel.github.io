Core Privacy Policy

Last updated: October 4, 2026

What Core accesses

Core uses the YouTube Data API and YouTube Analytics API with read-only permissions to view statistics of its owner's own YouTube channel, such as subscriber counts, views, watch time and video performance. Core cannot upload, edit or delete anything.

How the data is used

The data is used only to show the channel owner their own channel statistics. Core is a personal tool and is used by its owner only.

Storage and sharing

The access token is stored locally on the owner's own computer. Channel statistics are not sold, shared with, or transferred to any third party.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services

Core's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Core also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
